# 公文 OCR

把公文照片、截图或 PDF 扫描件识别成符合《党政机关公文格式》（GB/T 9704-2012）的 Word 文档。全部在本地运行，图片、PDF 和文字都不出本机。

## 功能

- 上传 JPG、PNG 或 PDF，或按 `Ctrl+V` 粘贴截图，自动识别文字并还原版面结构
- 一次可选最多 10 张 JPG/PNG，按选择顺序逐张识别，页与页之间自动插入分页符，最终合成一份 Word
- PDF 逐页处理：有文字层的页直接提取文字（比 OCR 准），纯扫描页渲染成图走 OCR；页与页之间自动插入分页符
- 自动判断每个段落属于哪一类：标题、发文机关标志、主送机关、一级/二级/三级标题、正文、发文机关署名、成文日期
- 识别结果按段落卡片展示，可直接修改错字、切换段落类型、增删段落（含插入分页符）
- 一键导出 docx，套用标准公文版式

## 公文版式

| 元素 | 格式 |
| --- | --- |
| 标题 | 黑体二号，居中 |
| 正文 | 仿宋三号，首行缩进 2 字，固定行距 28 磅 |
| 一级标题 | 黑体三号（`一、`） |
| 二级标题 | 楷体三号（`（一）`） |
| 三级标题 | 仿宋三号加粗（`1.`） |
| 发文机关署名 | 仿宋三号，右对齐 |
| 成文日期 | 仿宋三号，右对齐 |
| 页面 | A4，上 3.7 / 下 3.5 / 左 2.8 / 右 2.6 cm |
| 页码 | 宋体四号，居中 `— 1 —` |

数字和字母默认使用 Times New Roman。正文与标题字体可在界面工具栏中切换（正文可选仿宋_GB2312、华文仿宋；标题可选方正小标宋简体、宋体）。

## 环境要求

- Windows（已在 Windows 11 + Python 3.13 上验证）
- Python 3.10 及以上

## 安装

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

OCR 引擎为 RapidOCR（ONNX Runtime），首次识别时会自动加载内置的中文模型，无需额外下载或联网。

注意：`rapidocr-onnxruntime` 1.3 及以上只支持 Python < 3.12，本环境用 Python 3.13，因此依赖锁定为 1.2.3。

## 使用

双击 `run.bat`，脚本会按顺序寻找运行环境（项目内 `.venv` → `venv` → conda base），激活后启动服务并自动打开浏览器（http://127.0.0.1:8000）。

也可以手动启动（需先激活虚拟环境）：

```bat
.venv\Scripts\activate
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

然后访问 http://127.0.0.1:8000，拖入图片或 PDF 即可。图片可以一次多选（最多 10 张），识别结果按页分隔，导出时合并成一份 Word。

## 实现思路

OCR 返回的是带坐标的文字框，本程序用几何特征把它们还原成公文结构：

1. 按纵向位置聚类成视觉行，同一行被切碎的文字按间距拼回
2. 用中文字符的平均宽度估算字号（比边框高度稳定），明显大于正文且居中的行判为标题
3. 标题下方顶格、以冒号结尾的行判为主送机关
4. 以 `一、`、`（一）`、`1.` 开头的行判为各级标题
5. 缩进不足一字的行视为上一段的续行，据此合并跨行正文
6. 末尾符合日期格式的行判为成文日期，其上方右偏的行判为发文机关署名
7. 汉字之间被 OCR 误插的空格会自动去掉，英文和数字内部不动

PDF 用 PyMuPDF 解析：每页先取文字层，够 40 字就直接用（坐标为页面点，无需缩放）；否则按 200dpi 渲染成图，复用同一套 OCR 与结构化流程。

## 注意事项

- 识别准确率与原图清晰度直接相关，建议导出前在卡片里通读一遍
- 本机若未安装「仿宋_GB2312」，默认使用系统自带的「仿宋」，可在工具栏切换
- 单次上传总大小不超过 50MB；图片最多 10 张，PDF 需单独上传且最多 30 页，加密 PDF 需先解除密码
- PDF 里有文字层的页不走 OCR，扫描页才走；OCR 偶尔漏掉行末标点，导出前可在卡片里补上
- 结构化依赖版式特征，手写体、竖排、多栏排版或带表格的页面效果会明显下降
